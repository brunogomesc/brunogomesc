## 💫 About me

I design and build back-end systems, mostly with **C# / .NET**, **Angular** and **Python**, with the goal of improving people's lives through technology. I like clean architecture, design patterns, and automating whatever makes my routine slower.

- 🏗️ Focus: software architecture, REST APIs, authentication/authorization, cloud-native apps
- 🔭 Currently exploring: **Angular 20**, **Keycloak + ABP**, and AI agents for development
- 🌱 Always learning: observability (OpenTelemetry, Grafana), messaging (RabbitMQ) and cloud (Azure, AWS)
- 💬 Ask me about: C#, .NET, Angular, design patterns
